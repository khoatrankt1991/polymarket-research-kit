# Core Repositories of Polymarket

## 1. Smart Contracts and Blockchain Infrastructure

| Repository | Description |
|------------|-------------|
| `conditional-tokens-contracts` | Smart contracts managing conditional tokens based on ERC-1155, allowing creation and resolution of prediction markets |
| `conditional-tokens-market-makers` | Smart contracts managing liquidity and automated pricing (AMM) for prediction markets |
| `amm-maths` | Library of algorithms and mathematical formulas for calculating prices, liquidity, and profits |
| `uma-ctf-adapter` | Adapter integrating UMA Protocol for reliable oracles |
| `matic-withdrawal-batcher` | Handles batch withdrawals on the Polygon/Matic network |

## 2. Backend and Data Processing

| Repository | Description |
|------------|-------------|
| `polymarket-subgraph` | Subgraph definitions for indexing and querying data from the blockchain |
| `go-market-events` | Processing market events using Go |
| `resolution-subgraph` | Subgraph tracking market resolution processes |
| `polymarket-sdk` | Development toolkit for applications interacting with Polymarket |
| `routing-api` | API routing transaction requests to appropriate blockchain networks |

## 3. Front-end and User Experience

| Repository | Description |
|------------|-------------|
| `real-time-data-client` | Client handling real-time data |
| `vue-components` | Vue.js components for user interface |
| `leaderboard-username` | User leaderboard processing |
| `status-page-front` | Status page displaying system conditions |
| `web3-react-multichain` | React integration with multiple blockchains |

## 4. Trading and Order Book

| Repository | Description |
|------------|-------------|
| `clob-client` | Client for Centralized Limit Order Book |
| `clob-client-l2-auth` | Authentication for CLOB on layer 2 |
| `clob-order-utils` | Tools for processing trade orders |
| `ctf-exchange` | Conditional token exchange |
| `go-order-utils` | Order processing tools written in Go |

## 5. Tools and Utilities

| Repository | Description |
|------------|-------------|
| `poly-ct-scripts` | Scripts for managing conditional tokens |
| `balance-checker` | Balance checking tool |
| `polymarket-status-tool` | Tool for monitoring Polymarket system status |
| `multi-endpoint-provider` | Provider supporting multiple blockchain endpoints |
| `audit-checklist` | Checklist for auditing smart contracts |
